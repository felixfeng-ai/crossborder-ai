## P1：合规 Agent

状态：方案已确认，待开发。

目标：把现有文案合规、IP 风险初筛、认证声称、图片视觉检查和平台政策
检索收敛为一个可解释、可审计、可复检的合规 Agent。该 Agent 只做风险初筛
和整改建议，不输出“侵权成立”或“合法”等法律结论。

### 覆盖范围

- 广告法极限词、虚假宣传、绝对化用语
- 品牌、商标、Logo、水印、影视或卡通 IP 形象
- CE、FDA、UL、FCC、RoHS 等认证声称与证据完整性
- 平台、市场、类目政策要求
- Listing 文本、商品图、营销图和发布前门禁
- 人工授权声明、证据有效期和适用商品范围

### 统一后端服务

- [ ] 新增 `compliance_agent_service`，Agent 和普通页面都调用同一服务
- [ ] 收敛 `shopify.compliance_check`、`ai/compliance.py` 和 `ip_risk.py`
      中重复的规则实现
- [ ] 新增统一 `ComplianceContext`、`ComplianceFinding` 和
      `ComplianceReport` 数据契约
- [ ] 风险项统一包含 `code / category / severity / evidence /
      suggestion / source / policy_citation`
- [ ] AI 检查失败必须返回 `partial` 或 `unknown`，禁止把调用失败当作
      `safe=true`
- [ ] 检查结果保留规则版本、政策版本和模型版本
- [ ] 相同输入和相同版本复用历史报告，避免重复调用模型

### 分层检测架构

1. 确定性规则引擎：品牌词、极限词、认证声称、类目授权链
2. 平台政策 RAG：平台、市场、类目过滤，必须返回可点击的政策来源
3. AI 文本复核：上下文、语义、虚假授权和改写风险
4. AI 图片复核：Logo、水印、角色 IP 和可见商标文字
5. 风险聚合：高风险硬拦截，`unknown` 不得直接通过
6. 整改建议：生成可执行改写方案，用户确认后才能写回 Listing
7. 自动复检：整改完成后重新执行同一规则和证据检索
8. 发布门禁：保留中断原因、覆盖率和人工复核状态

### 合规 Agent 工作台

- [ ] 新增“合规 Agent”入口，不复制普通聊天页
- [ ] 支持从商品、Listing、营销图或自定义文本发起检查
- [ ] Tab：文案、图片、政策依据、整改建议、历史报告
- [ ] 支持平台、市场、类目、授权声明和证据文件
- [ ] 风险卡展示命中片段、图片区域、政策引用和整改动作
- [ ] 显示检查覆盖率，不只展示“通过/不通过”
- [ ] 支持一键生成整改方案、用户确认、写回和自动复检
- [ ] 发布按钮与合规报告联动，高风险和未完成检查必须阻断

### 政策 RAG

- [ ] 复用现有 Qdrant + 关键词降级检索，不另建平行知识库
- [ ] 政策来源必须包含平台、市场、类目、版本、生效时间和原文 URL
- [ ] 建立政策定时同步、版本更新和过期提醒
- [ ] 建立至少 30 题政策检索评测集
- [ ] 建立文案、图片、认证和品牌授权回归样例集
- [ ] 监控检索命中率、引用准确率、误报率、漏报率和模型成本

### 非目标

- 不做专利查新、权利要求拆解或商标近似算法
- 不让模型直接修改 Listing 后自动发布
- 不把 Agent 输出作为法律意见或平台最终审核结论
- 不在第一版自动抓取所有平台政策全文；先覆盖 Amazon、TikTok Shop、
      Shopify、Temu、SHEIN 的核心上架和图片规则

### 验收门槛

- 同一输入在同一规则/政策版本下结果可复现
- 每条风险都能定位到具体文本片段或图片 bbox
- 每条政策风险至少有一个可访问来源，没有依据时明确显示未检索到
- AI 或视觉模型不可用时仍完成规则检查，并标记未覆盖项
- 高风险 Listing 无法发布，整改并复检后才能解除阻断
- 合规 Agent 与 Listing 页面使用同一份 `ComplianceReport`

## P1：React Native 移动端

状态：未启动，后续处理。

### 产品定位

移动端采用“移动运营助手”，不直接一比一复制桌面 Web：

- AI 助手对话与任务提交
- 营销成片、专业分镜和商品视频的生成进度
- 视频预览、下载、分享与失败重试
- 商品拍照、相册上传和自有商品快速录入
- 审批、待办与任务通知

- 完整 Listing 编辑器
- 复杂商品变体表格
- 批量图片工作台
- 专业分镜长文本编辑器
- 管理后台、升级审核和完整账单操作
- 复杂店铺授权和渠道配置

- SecureStore 保存登录令牌
- expo-image-picker / expo-document-picker 处理上传
- expo-video / expo-file-system 处理视频预览和下载
- APNs / FCM 处理任务完成、失败和审批通知
