# VeyaShip 定价与年末增长季

## 目标

把现有单一月度套餐升级为“日常价 + 新客首月优惠 + 年付优惠 + 首购体验包”，同时修正图片、视频、配音和商品抓取的积分成本，保证活动可解释、可审计且媒体功能不产生负毛利。

## 活动

- 活动名称：2026 年末增长季
- 活动时间：2026-11-12 至 2026-11-30，Asia/Shanghai
- 新客首月：Standard ¥79，Professional ¥199
- Professional 新客首月额外赠送 100 积分
- 年付：Standard ¥990，Professional ¥2,490
- 首购体验包：50 积分 / ¥9.9，成功购买一次后不再具备资格
- 新客首月优惠与年付优惠不可叠加

## 能力点

### 1. 套餐报价

**Requirement**

服务端必须根据当前用户、计费周期和活动资格返回可信的应付金额，前端传入的价格不能成为结算依据。

**Scenario**

- Given 新用户当前为 Free 且从未开通过付费套餐
- When 提交 Standard 月付升级
- Then 应付金额为 ¥79，有效期 30 天

- Given 同一新用户提交 Professional 月付升级
- When 管理员审核通过
- Then 开通 30 天 Professional，并额外到账 100 购买积分

- Given 用户选择年付
- When 提交 Standard 或 Professional 升级
- Then 分别按 ¥990 / ¥2,490 创建订单，有效期 365 天

- Given 用户已有付费历史
- When 再次提交月付升级
- Then 不重复享受新客首月价格，按日常价 ¥99 / ¥249 创建订单

### 2. 首购体验包

**Requirement**

首购体验包只允许成功购买一次，待处理或已通过订单都视为已使用资格。

**Scenario**

- Given 用户从未购买体验包
- When 创建体验包订单
- Then 订单为 50 积分、¥9.9、pending

- Given 用户存在 pending 体验包订单
- When 再次创建体验包订单
- Then 返回原订单，不重复创建

- Given 用户已有 approved 体验包订单
- When 再次创建体验包订单
- Then 返回 409，并说明首购资格已使用

### 3. 功能积分

**Requirement**

高成本媒体能力按服务端配置扣积分，页面不得成为唯一计价来源。

**Scenario**

- AI 图片：每张 3 积分
- H3-Lite 480P：12 积分 / 4 秒
- H3-Lite 768P：18 积分 / 4 秒
- H3 2K：60 积分 / 4 秒
- AI 配音：每 100 字符 1 积分，最低 3 积分
- 商品抓取：套餐内包含额度，超出后每次 2 积分

### 4. 页面展示

**Requirement**

账单页沿用 VeyaShip 石墨工作台，首屏必须同时展示活动价、日常价、优惠金额和主要权益；月付与年付切换后价格同步变化。

**Scenario**

- Given 用户进入账单页
- When 活动仍在有效期内
- Then 显示活动价和剩余活动日期
- 月付 / 年付切换更新套餐价格和按钮文案
- 首屏必须同时展示当前账户摘要、活动价格和至少一种真实产出预览
- 提供成片、商品图和 Listing 的积分换算预览，示例素材需明确标注
- 已使用首购资格时不再显示可购买体验包
- 窄屏 390px 无横向溢出

### 5. 审计与兼容

- 升级订单保存 billing_cycle、promotion_code、original_amount、bonus_credits、duration_days
- 管理员审核页面显示计费周期和优惠来源
- 历史订单默认按月付、无优惠兼容
- 迁移可在 SQLite 与 PostgreSQL 执行

## 非目标

- 本次不接支付网关，继续使用人工转账审核
- 本次不实现订阅自动续费
- 本次不调整模型供应商价格，只调整平台收取积分

## 验收

- 后端相关测试通过
- 前端类型检查、单测与生产构建通过
- 账单页在 1440 / 768 / 390 宽度真实验收
- 计费金额始终由服务端决定
