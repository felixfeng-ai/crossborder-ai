# 1688 货源发现与供应商候选

> 状态：已确认实施
> 日期：2026-11-24
> 范围：Amazon 候选商品到 1688 货源候选的 MVP 链路。

## SOURCE-01 关键词货源搜索

### Requirement

决策 Agent 必须能从 Amazon 候选商品生成中文采购关键词，并查询 1688 商品列表。
搜索优先使用 Just One API，失败或不可用时降级到 Onebound。

### Scenario

- Given 用户选择了一个 Amazon 候选商品
- When 用户点击“1688 找货源”
- Then Agent 使用商品核心词和规格搜索 1688
- And 返回价格、MOQ、销量、店铺、发货地、工厂标记和商品链接
- And 标明实际搜索供应商与观察时间

## SOURCE-02 图片相似货源

### Requirement

Amazon 候选商品存在公开主图时，Agent 必须先尝试 1688 图片相似搜索。
图片搜索失败时自动降级到关键词搜索，不阻断流程。

### Scenario

- Given 候选商品有公开主图 URL
- When Agent 发起货源搜索
- Then 优先返回图片相似货源
- And 结果明确标记为“相似货源”，不能宣称与 Amazon 商品完全相同

## SOURCE-03 候选商品入口

### Requirement

Agent 选品报告中的每个 Amazon 候选商品必须提供“1688 找货源”操作。
操作必须带入商品名称、ASIN 和可选主图，不自动询价或下单。

## SOURCE-04 选定货源后的下一步

### Requirement

1688 货源候选必须允许用户选择货品并进入真实利润分析。
利润分析继续使用具体 1688 链接、SKU 采购价、物流、平台佣金和履约费用。

### Scenario

- Given 用户从货源列表选定一个 1688 商品
- When 用户点击“用这个货源算利润”
- Then Agent 进入现有 `analyze_product_decision` 流程
- And 缺少采购价、物流或平台费用时明确要求补充

## SOURCE-05 生产安全边界

- API Key、完整供应商响应和用户图片不得写入日志。
- 搜索结果只作为公开市场线索，不保证同款、质量、授权或供货稳定性。
- 不自动联系供应商、申请样品、加购、下单或付款。
- 搜索 API 成本需要按用户操作计量，并避免重复查询同一关键词和图片。
