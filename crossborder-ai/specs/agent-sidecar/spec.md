# AI 决策助手全局侧栏

## 目标

让商家在图片工作台、视频工作台及其他经营页面中直接使用 AI 决策助手，
无需切换菜单，并让 Agent 理解当前页面上下文。

## Requirement 1：全局入口

### Scenario

Given 用户已登录且不位于完整 Agent 页面
When 用户点击右下角机器人按钮或按下 Alt+A
Then 当前路由保持不变，并打开 AI 决策助手侧栏。

### 验收

- 完整 Agent 页面不显示重复入口。
- 桌面端显示为右侧侧栏，移动端显示为底部抽屉。
- Escape 关闭侧栏，并把焦点还给入口按钮。

## Requirement 2：任务连续性

### Scenario

Given Agent 正在执行任务
When 用户关闭侧栏
Then 任务继续执行，重新打开后仍能看到该会话和任务结果。

### 验收

- 关闭侧栏不得卸载正在运行的会话状态。
- 重新打开后保留消息、输入草稿和当前会话。

## Requirement 3：页面上下文

### Scenario

Given 用户正在图片工作台或视频工作台的某个模式
When 用户向侧栏 Agent 发送指令
Then 请求携带当前路由、页面名称和安全的页面元数据。

### 验收

- 图片工作台带入当前素材 ID、素材名称和平台预设。
- 视频工作台带入当前 Tab。
- 上下文以可见标签展示，可移除。
- 不传本地 File、图片二进制或敏感凭据。

## Requirement 4：会话复用

### Scenario

Given 用户已经使用完整 Agent 页面
When 用户打开侧栏
Then 侧栏复用相同后端 `/agent/run`、SSE 和会话历史，不建立平行聊天系统。

## Requirement 5：响应式与可访问性

### Scenario

Given 用户使用 1440px 桌面或 390px 移动设备
When 侧栏打开
Then 正文、快捷操作和输入框不重叠、不溢出，并保持可操作。

### 验收

- 全部触控按钮至少 44px。
- 支持 reduced-motion。
- 移动端打开时锁定背景滚动，关闭后恢复。
