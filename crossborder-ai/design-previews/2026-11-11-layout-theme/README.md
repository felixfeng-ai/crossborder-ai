# VeyaShip 布局与主题方向

## 设计读取

读取为：跨境卖家 AI 经营工作台，面向每天高频处理商品、Listing、图片、SKU 和平台发布的卖家与运营人员，用成熟、精密、可信的生产工具语言，倾向中性石墨、纸白命令和低饱和琥珀信号的制作台美学。

三个拨盘：

- 视觉冒险度 5/10：保留工作台结构，不靠夸张构图制造所谓高级感。
- 动效强度 3/10：动效只解释状态和空间关系，不做持续装饰。
- 信息密度 6/10：中等偏高，保证运营信息可扫读，同时保留必要呼吸。

## 现状问题

- 主题同时使用暖黑、琥珀高饱和主色、紫蓝品牌色残留、毛玻璃、渐变按钮、aurora 光晕、颗粒、大圆角和重阴影，没有一个统一的视觉决定。
- 页面由四宫格快捷入口、四张 KPI 卡片、卡片套卡片连续堆叠，缺少唯一主角。
- 中文正文使用 Inter 作为前置西文字体，数字也没有稳定的表格数字规则，导致中文工具界面缺少高级感和专业密度。
- 移动端四个快捷入口挤成四列，“AI 助手”等标签发生断行。

## 四个方向

- A 石墨决策台：中性石墨层级、纸白主操作、低饱和琥珀状态；232px 侧栏和连续工作区。推荐。
- B 纸墨决策台：珍珠灰纸面、编辑式标题、经营事实列；品牌感更强，但不适合极高频密集操作。
- C 指挥轨工作台：顶部导航、图标轨和停靠 AI 指挥台；适合高级用户和长时间 Agent 运行。
- D 瓷白 AI 舱：亮色主画布与独立 AI 舱分工；适合偏轻量、通透的 AI 产品感。

推荐 A，因为它在保留平台现有琥珀识别的同时，最接近 drama-outline 的成熟生产工具气质，也最能承受商品、图片、SKU 和发布等高频操作。

字体严格与 drama-outline 保持同一事实：中文优先使用 PingFang SC、Noto Sans SC、Microsoft YaHei、HarmonyOS Sans SC、MiSans 系统栈；西文和普通数字使用 Inter；编号、金额、积分、SKU 和耗时使用 JetBrains Mono。四个方向不通过更换字族制造差异。

跨境平台不应复制短剧业务布局。共享的是字体、石墨明度层级、纸白命令和状态色纪律；页面主角改为商品证据、利润、合规、SKU、渠道状态和待决策队列。推荐方向名为「石墨决策台」。

本目录是方向样机，不是最终页面。确认方向后才修改正式前端。
