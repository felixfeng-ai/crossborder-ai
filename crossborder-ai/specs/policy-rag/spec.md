# 跨境平台政策 RAG P0 规格

## 目标

为 Amazon、TikTok Shop、Shopify 等平台政策建立可版本化、可引用、可降级检索的
知识库，并为 AI 决策助手提供政策查询工具。

确定性合规规则仍然是发布 Gate 的唯一判定依据。RAG 只提供政策原文、解释依据和
整改建议，不得覆盖或绕过确定性规则。

## 能力点

### R1 政策来源管理

- 政策来源必须记录平台、市场、类目、文档类型、版本、生效时间、原始链接和内容校验和。
- 同一来源版本重复导入时不得生成重复切分。
- 来源内容变化后，旧切分必须失效。

### R2 文档切分

- 优先按 Markdown 标题层级切分。
- 单个切分不得超过配置的字符上限。
- 每个切分保存标题路径和内容哈希。
- 切分过程不得把两个无关政策合并到同一片段。

### R3 向量入库

- 使用 DashScope OpenAI 兼容 Embedding 接口。
- 默认模型为 `text-embedding-v4`，默认维度为 1024。
- 向量写入独立 Qdrant Collection。
- Qdrant 写入失败不得阻断 PostgreSQL 文本入库。

### R4 政策检索

- 支持按平台、市场、类目过滤。
- 返回正文片段、来源标题、来源链接、版本、生效时间、相似度和切分 ID。
- 检索无可靠结果时必须明确返回无依据，不得编造。
- Qdrant 或 Embedding 不可用时，降级为 PostgreSQL 关键词检索。

### R5 Agent 工具

- AI 决策助手新增 `search_platform_policies` 工具。
- 用户询问平台规则、认证要求或 Listing 合规依据时使用。
- 工具结果必须包含引用来源。

### R6 管理 API

- 管理员可以导入政策文本并查看来源列表。
- 普通卖家只能检索已启用政策，不能写入全局知识库。

## 非目标

- 不做自动抓取所有动态平台网页。
- 不做 Graph RAG。
- 不做法律结论或侵权判定。
- 不将用户私有材料混入平台政策 Collection。

## 验收

- 单元测试覆盖切分、幂等导入、过滤检索和关键词降级。
- Qdrant 不可用时检索仍返回文本结果。
- Agent 工具返回来源引用。
- 现有合规、IP 风险和发布 Gate 测试全部通过。
