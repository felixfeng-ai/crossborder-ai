# 移动端功能链路修复规格

> 状态：已确认，按顺序执行  
> 日期：2026-11-22  
> 范围：App 与移动 API 的真实行为修复，不包含无关视觉重构。

## 1. 生成图片真实保存到素材库

- 素材任务已有生成图片时，“保存到素材库”必须调用后端幂等保存接口。
- 保存成功后进入素材库；失败时保留当前页面并允许重试。
- 同一生成任务重复保存不得产生重复素材。

## 2. 业务日期与工作区时区一致

- 时间线、今日计划和日结使用同一时区。
- `Asia/Shanghai` 等非 UTC 时区在跨 UTC 日界时仍按本地业务日期归类。
- 移动端请求时间线与计划时显式携带设备时区。

## 3. 网络错误与业务状态分离

- 任务详情请求失败时显示同步错误和重试，不显示“已失效”。
- Agent 详情请求失败时显示同步错误和重试，不永久显示“处理中”。
- 通知和素材库请求失败时显示错误状态，不显示空状态。

## 4. 工作区上下文

- 账号页可切换当前工作区。
- 深链携带 `workspaceId` 时先切换工作区，再进入目标页面。
- 不可操作的界面元素不得显示箭头等可点击暗示。

## 5. 离线文案真实性

- 手机离线只表示当前 App 无法同步。
- 文案不得声称后端 Agent 暂停。

## 6. 客户快捷入口唯一分类

- 每个 `customer_reply` 只归入一个分类。
- 优先级：投诉与风险 > 评价回复 > 待回复消息。

## 7. 素材库筛选后排序

- 筛选状态下前移和后移只改变当前可见素材的相对顺序。
- 隐藏素材相对顺序保持不变。

## 8. 通知已读与图标

- 点击单条通知先标记该条已读，再导航。
- 全部已读继续保留。
- `action_failed` 使用警告语义图标。

## 9. 通知偏好

- 账号页提供通知偏好入口。
- 支持晨报、日结、待处理、执行失败、授权过期开关。
- 支持免打扰起止时间与 IANA 时区。
- viewer 只读，owner/admin/operator 可修改。

## 10. 真实店铺筛选

- 新增工作区商店清单 API，返回平台、名称、连接状态，不返回凭据。
- 首页选择店铺后，时间线、今日计划、通知和功能入口计数按店铺过滤。
- `WorkItem` 增加可空平台和商店归属字段，历史未归因任务只在“全部店铺”显示。
- 选择结果持久化。

## 11. 素材描述编辑与参考图重选

- 素材任务详情返回原描述和当前参考素材。
- 可修改描述、重选参考图并提交新的生成动作。
- 新动作保留原任务历史，使用幂等键，不重复扣费。

## 12. 视频保存到系统相册

- “保存视频”执行真实下载并写入系统相册。
- iOS/Android 请求相册写入权限。
- 成功、权限拒绝、链接过期和网络失败分别处理。
- 签名 URL 不写入日志或用户可见错误。

## 验收门禁

- 每个需求先写失败测试，确认失败原因来自缺失行为。
- 移动端测试、TypeScript、ESLint 全量通过。
- 后端相关测试通过；逻辑模块覆盖率不低于 80%。
- 真实运行检查首页、账号、通知、素材库、素材成功页和错误页。
