# 营销 Agent 与快捷指令稳定性

## 目标

将通用 Agent 能力复用到营销垂直场景，提供独立“营销 Agent”入口；
同时修复对话历史异步加载导致快捷指令闪现后消失的问题。

本阶段复用现有 Agent、图片生成、视频生成和素材查询工具，不复制执行引擎。

## 能力一：营销 Agent

### Requirement

营销 Agent 与通用 AI 助手共用 `/agent/run` 和任务流，但使用营销专用欢迎语、
快捷指令、输入提示和工作区导航。

### Scenario: 进入营销 Agent

- Given 用户从侧栏进入“营销 Agent”
- Then 页面展示营销目标和多素材能力
- And 提供营销方案、商品主图、场景图、营销视频、广告文案快捷指令
- And 可以跳转图片工作台、视频工作台和素材中心
- And 对话历史与通用 AI 助手分开

### Scenario: 复用执行引擎

- Given 用户提交营销需求
- When Agent 选择工具
- Then 继续使用现有图片、视频和素材能力
- And 不创建第二套任务队列或积分逻辑

## 能力二：快捷指令稳定展示

### Requirement

快捷指令不得因为历史对话异步加载而闪现后消失。

### Scenario: 加载历史对话

- Given 页面首屏正在加载历史消息
- When 历史加载完成并替换消息列表
- Then 快捷指令仍然保持可见
- And 不产生布局跳动

### Scenario: 长对话

- Given 当前对话已经有多条消息
- Then 快捷指令仍作为紧凑横向工具条显示在输入框上方
- And 不占用主要对话空间

## 验收标准

- 通用 Agent 与营销 Agent 的文案和快捷指令不同。
- 两个入口共用同一个 Agent API。
- 历史消息加载前后快捷指令均为可见状态。
- 桌面和 390px 移动端完成真实截图验证。
